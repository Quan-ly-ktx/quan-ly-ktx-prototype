This project is a Vite + React + TypeScript frontend prototype

`public/` - Static files that are served directly by Vite.

`src/` - Main application source code.

`src/assets/` - Local images, icons, and other imported assets.

`src/components/` - Reusable UI components.

  - `src/components/common/` - Shared UI elements (buttons, modals, tables, notification, etc.).

`src/config/` - Central application and API configurations.

`src/contexts/` - Shared React context providers and global state.

`src/hooks/` - Custom React hooks.

`src/pages/` - Page-level views and screen containers.

`src/routes/` - Route definitions, navigation setup, and route guards.

`src/services/` - API calls, HTTP client, and data access logic.

`src/styles/` - Shared styling rules and variables.

`src/test/` - Test utilities and Vitest setup.

`src/types/` - TypeScript models, interfaces, and API entity definitions.

  - `src/types/api/` - Request and response types for backend endpoints.

`src/utils/` - Helper functions, formatters, and utility code.

`src/App.tsx`, `src/main.tsx`, and `src/index.css` - Application entry points and global styling.
